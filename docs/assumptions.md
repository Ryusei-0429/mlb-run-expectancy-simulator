# assumptions

## 野球状態モデル（最小仕様）

状態は次の組で表現する。

- アウト数: `outs in {0,1,2}`
- 走者状況: `on_first`, `on_second`, `on_third`（真偽値）
- 打順位置: `batter_index`（0始まり）

3アウト到達でイニング終了（終端状態）とする。

## 打席結果（最小集合）

- out
- single
- double
- triple
- home_run
- walk
- hit_by_pitch
- sacrifice_fly
- double_play

## 初期実装での単純化（研究上の仮定）

1. 盗塁・牽制死・暴投・捕逸・ボークは無視する。
2. 進塁処理は決定論的ルール（例: 単打で各走者+1塁）を初期値とする。
3. 犠飛は 1アウト増加とし、三塁走者がいる場合のみ 1得点を基本とする。
4. 併殺打は 2アウト増加（ただし最大3アウト）とし、一塁走者がいる場合を主対象とする。
5. 打席結果確率の総和は浮動小数点誤差を除き `1.0 ± 1e-9` を許容する。

## 実データと仮定データの区別

- MLB Stats API 由来データは `data/raw/` に保存する。
- 研究用仮定値・補完値は `data/processed/` と実験ログに明記する。
