# Issue案: マルコフ連鎖による最小実装

## 背景
打席結果確率と塁・アウト状態を用いた、再現可能な得点期待値計算の最小実装を作成する。

## 目的
- 1イニングの状態遷移をマルコフ連鎖で表現する
- 期待値と得点分布の基本計算を可能にする
- 解析解とモンテカルロ結果の整合性を確認できる基盤を作る

## 作業内容
- 状態モデル（outs / bases / batter_index）のデータ構造を実装
- 打席結果ごとの遷移関数を実装
- 遷移確率総和チェック（許容誤差付き）を実装
- 3アウト終端処理を実装
- 最小テストを追加（確率合計・終端処理・本塁打得点）

## 完了条件
- 指定した状態・確率分布から期待値計算ができる
- 同一シードでモンテカルロ結果が再現する
- 主要テストが通る

## 既知の制約
- 盗塁や走塁死などの事象は初期版で未対応
- 進塁モデルは単純化ルールを採用
