# design_open_questions

## 実装前の不明点

1. 進塁処理を「完全決定論」で始めるか、「確率遷移」で始めるか。
2. 犠飛・併殺打の発生確率を打者個別に持つか、リーグ平均で補完するか。
3. 打席結果確率の推定期間（シーズン全体/直近N試合）をどう定義するか。
4. 9人全順列探索を初期版で行うか、ヒューリスティック探索を先行するか。
5. 得点分布の打ち切り上限（例: 1イニング最大何点まで追跡）をどう置くか。

## 当面必要な仮定

- 初期版は決定論的進塁ルールを採用する。
- 欠損データはゼロ埋めせず、除外または推定値で補完しログに残す。
- API取得失敗時は例外を明示し、キャッシュ済みデータ利用可否を切り替える。
- モンテカルロ比較は許容誤差（例: 期待値差 0.05 以下）を定義して検証する。
